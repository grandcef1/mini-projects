# .noclips — мини-проекты

Сайт-портфолио начинающего frontend-разработчика. Здесь собраны небольшие проекты на чистом HTML, CSS и JavaScript — без фреймворков и сборщиков, только код и его поведение в боевых условиях.

## О чём сайт

- демонстрация мини-проектов
- практика фронтенд-разработки
- портфолио начинающего разработчика

## Проекты

### Калькулятор
Обычный калькулятор, но с характером: цифры, скобки, базовые операции, плавные анимации и защита от ошибочного ввода.

### Конвертер валют
Актуальные курсы через [ExchangeRate API](https://www.exchangerate-api.com/). Пересчёт между пятью валютами: белорусские рубли (BYN), доллары (USD), евро (EUR), российские рубли (RUB) и китайские юани (CNY). Пока курсы загружаются, интерфейс предупреждает об этом. Результат выводится с точностью до трёх знаков.

### Список задач
Добавление, редактирование и удаление задач. Таблица с фильтрацией по статусу и дате (сначала невыполненные или от старых к новым). Три статуса задач, кастомные модальные окна, плавные анимации. Данные хранятся в браузере, поэтому задачи сохраняются после перезагрузки страницы.

### Таймер и секундомер
- **Таймер:** обратный отсчёт с установкой часов, минут и секунд, наглядная индикация оставшегося времени и звуковой сигнал по окончании.
- **Секундомер:** прямой отсчёт с точностью до сотых и фиксацией кругов в таблицу.
- Некорректные значения в полях исправляются автоматически, настройки сохраняются при переключении режимов.

### Музыкальный плеер
Плеер для собственных треков. Загрузка файлов перетаскиванием или через выбор (до 30 МБ), плейлист с переименованием и удалением треков, автосохранение в браузере. Play/pause, переключение треков по кругу, shuffle и автопереход к следующему. Во время воспроизведения работает визуализатор спектра в реальном времени, а вместо меню танцуют анимированные персонажи. Треки хранятся в облаке Cloudinary, поэтому нужен интернет.

## Структура репозитория

```
mini-projects/
├── index.html          # главная страница
├── aboutMe.html        # страница «Обо мне»
├── calculator.html     # страница с мини-проектами
├── aboutMeJS/          # скрипты страницы «Обо мне»
├── calculatorJS/       # скрипты мини-проектов
├── indexJS/            # скрипты главной страницы
├── css/                # стили
├── fonts/              # шрифты
├── gif/                # анимации
├── icons/              # иконки
├── particles/          # фоновые анимации (частицы, звёздное небо)
├── pictures/           # скриншоты проектов
└── sounds/             # звуки (сигнал таймера и др.)
```

Все мини-проекты открываются через одну страницу `calculator.html` и переключаются параметром в адресе:

| Проект | Адрес |
| --- | --- |
| Калькулятор | `calculator.html` |
| Конвертер валют | `calculator.html?mode=converter` |
| Список задач | `calculator.html?mode=ToDoList` |
| Таймер | `calculator.html?mode=timer` |
| Музыкальный плеер | `calculator.html?mode=music` |

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- `fetch` / async-await для работы с API
- `localStorage` для сохранения данных
- Библиотеки: [AOS](https://michalsnik.github.io/aos/) (анимации при прокрутке), [particles.js](https://vincentgarreau.com/particles.js/), [Vanta.js](https://www.vantajs.com/) (глобус) и [three.js](https://threejs.org/)

## Запуск

Сборка не нужна. Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/grandcef1/mini-projects.git
cd mini-projects
```

Для работы конвертера валют и подгрузки библиотек с CDN нужен интернет. Если браузер блокирует часть функций при открытии файла напрямую, запустите локальный сервер, например:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.
