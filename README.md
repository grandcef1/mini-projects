## 🚀 Проекты

Все мини-проекты открываются через одну страницу `calculator.html` и переключаются параметром в адресе.

| Проект | Адрес |
| --- | --- |
| 🧮 Калькулятор | `calculator.html` |
| 💱 Конвертер валют | `calculator.html?mode=converter` |
| ✅ Список задач | `calculator.html?mode=ToDoList` |
| ⏱ Таймер и секундомер | `calculator.html?mode=timer` |
| 🎵 Музыкальный плеер | `calculator.html?mode=music` |

### 🧮 Калькулятор
Обычный калькулятор, но с характером: цифры, скобки, базовые операции, плавные анимации и защита от ошибочного ввода.

### 💱 Конвертер валют
Актуальные курсы через [ExchangeRate API](https://www.exchangerate-api.com/).

- пересчёт между пятью валютами: **BYN**, **USD**, **EUR**, **RUB**, **CNY**
- пока курсы загружаются, интерфейс предупреждает об этом
- результат выводится с точностью до трёх знаков

### ✅ Список задач
Добавление, редактирование и удаление задач.

- таблица с фильтрацией по статусу (сначала невыполненные) и по дате (от старых к новым)
- три статуса задач: «Не выполнено», «В процессе», «Выполнено»
- кастомные модальные окна и плавные анимации
- данные хранятся в браузере и сохраняются после перезагрузки страницы

### ⏱ Таймер и секундомер

| Режим | Возможности |
| --- | --- |
| **Таймер** | обратный отсчёт с установкой часов, минут и секунд, наглядная индикация оставшегося времени, звуковой сигнал по окончании |
| **Секундомер** | прямой отсчёт с точностью до сотых, фиксация кругов в таблицу |

Некорректные значения в полях исправляются автоматически, настройки сохраняются при переключении режимов.

### 🎵 Музыкальный плеер
Плеер для собственных треков.

- загрузка файлов перетаскиванием или через выбор (до 30 МБ)
- плейлист с переименованием и удалением треков, автосохранение в браузере
- play/pause, переключение треков по кругу, shuffle и автопереход к следующему
- **визуализатор спектра** в реальном времени
- вместо меню во время воспроизведения танцуют анимированные персонажи 🕺
- треки хранятся в облаке [Cloudinary](https://cloudinary.com/), поэтому нужен интернет

## ⚡ Запуск

Сборка не нужна. Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/grandcef1/mini-projects.git
cd mini-projects
```

> 🌐 Для работы конвертера валют, загрузки треков и подгрузки библиотек с CDN нужен интернет.

Если браузер блокирует часть функций при открытии файла напрямую, запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте <http://localhost:8000>.
